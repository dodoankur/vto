# 3D Models Directory

This directory contains 3D models for eyewear frames in GLB/GLTF format.

## Model Requirements

- Format: GLB or GLTF
- Size: < 5MB per model
- Optimized for web rendering
- Include proper materials and textures

## Default Models

Place your 3D frame models here. The application will look for:
- `default-frame.glb` - Default frame model
- Frame-specific models referenced by the API

## Model Structure

Each frame model should include:
- Frame geometry
- Lens geometry (optional)
- Materials and textures
- Proper scaling and positioning
